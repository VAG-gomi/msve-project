# experiments-and-results — scope note

**No experiments were ever authorised or run in the MSVE project.** Every
work order explicitly withheld implementation, solver integration, and
experimental execution. This directory is intentionally empty; its emptiness
is a true record of project scope, not a gap in preservation.

The closest surviving material is solver-model evidence (Z3 checks of the
formal model), preserved under `../work-orders/` and described in
`VERIFICATION_HISTORY.md`. Those are *model* checks, not engine experiments.
